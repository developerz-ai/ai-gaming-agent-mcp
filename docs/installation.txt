AI GAMING AGENT - Installation Guide
====================================

The agent ships as the Python package `ai-gaming-agent` (version 0.2.0).
It installs one console command: `gaming-agent`.
There is no installer script; install it with pip.


SYSTEM REQUIREMENTS
-------------------
  - Python 3.12 or higher
  - 4GB RAM minimum (8GB recommended)
  - Network connectivity to Master Claude
  - A graphical desktop session (mouse, keyboard and screenshot tools
    need a display)

For Local VLM (optional):
  - NVIDIA GPU with 4-8GB VRAM
  - CUDA drivers installed
  - Ollama (installed via the `vlm` extra, see below)


INSTALL FROM PYPI
-----------------
  1. Create and activate a virtual environment

     python -m venv ~/.gaming-agent/venv
     Windows:   %USERPROFILE%\.gaming-agent\venv\Scripts\activate
     Linux/Mac: source ~/.gaming-agent/venv/bin/activate

  2. Install the package (dependencies are pulled in automatically)

     pip install ai-gaming-agent

  3. Optional: add the local VLM support (Ollama client)

     pip install "ai-gaming-agent[vlm]"


INSTALL FROM SOURCE
-------------------
The application lives in apps/ai-gaming-agent-mcp inside the repository.

  1. Clone the repository

     git clone https://github.com/developerz-ai/ai-gaming-agent-mcp.git
     cd ai-gaming-agent-mcp/apps/ai-gaming-agent-mcp

  2. Create and activate a virtual environment (as above)

  3. Install in editable mode

     pip install -e .

  Extras: `vlm` (Ollama), `dev` (ruff, pytest) and `integration`
  (pytest, pytesseract), e.g. pip install -e ".[dev]"


CONFIGURATION
-------------
Create the config file at ~/.gaming-agent/config.json:

  gaming-agent init --password YOUR_PASSWORD --port 8765

Options: --password, --port, --force (overwrite an existing config).
Show the current configuration with:

  gaming-agent config

See configuration.txt for every setting. A remote PC must list its own
host and port in server.allowed_hosts (for example "192.168.1.100:8765"),
otherwise every /mcp request is refused with HTTP 421.


RUNNING THE SERVER
------------------
  gaming-agent serve                      HTTP/SSE transport (default)
  gaming-agent serve --transport stdio    stdio transport for a parent MCP client

Options for serve: --transport {stdio,http}, --host, --port, --password,
--config (path to a config file).

Check the installed version:

  gaming-agent --version


POST-INSTALLATION
-----------------
  1. Start the server with `gaming-agent serve`
  2. Verify it is running (default port 8765):
       curl http://localhost:8765/health
     Expected: {"status": "ok", "version": "0.2.0"}
  3. Point Claude at the MCP endpoint http://PC_IP:8765/mcp and send
     the password as a Bearer token


UNINSTALLATION
--------------
  pip uninstall ai-gaming-agent

To also remove the configuration, delete the ~/.gaming-agent directory.


UPDATING
--------
From PyPI:
  pip install --upgrade ai-gaming-agent

From a source checkout:
  git pull
  pip install -e .
